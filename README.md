# Customer_behavior_analysis
Data analyst project using python ,SQL and power bi
## 📌 Project Overview

This project analyzes customer shopping behavior using **Python, SQL, and Power BI** to identify purchasing patterns, customer preferences, product performance, and factors influencing sales.

The goal of this project is to transform raw customer shopping data into meaningful insights that can support **data-driven business decisions**.

---

## 🎯 Objectives

- Analyze customer purchasing behavior
- Identify high-performing product categories
- Understand customer demographics and spending patterns
- Analyze the impact of discounts and subscriptions
- Identify top-rated products
- Examine shipping preferences
- Segment customers based on their purchasing behavior
- Build an interactive dashboard to present key insights

---

## 🗂️ Dataset

The dataset contains **3,900 customer purchase records** and **18 columns**.

### Key Features

- Customer information
- Age and gender
- Product and category
- Purchase amount
- Discount information
- Review rating
- Subscription status
- Shipping type
- Payment method
- Purchase frequency
- Previous purchases

The dataset contains **37 missing values**, primarily in the review rating column.
